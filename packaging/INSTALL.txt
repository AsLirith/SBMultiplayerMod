SBMultiplayer - unofficial multiplayer mod for STUNTBOOST
==========================================================

! While the mod is loaded, the game does NOT save any time, neither online nor locally.
  To uninstall, just remove the Steam launch option.

1) Copy the "SBMultiplayer" folder into the game folder
   (Steam > STUNTBOOST > right click > Manage > Browse local files).
   Updating? Just overwrite the files: your settings are kept.

2) Steam > STUNTBOOST > Properties > Launch options:

   Linux:
     DOTNET_STARTUP_HOOKS="/path/to/STUNTBOOST/SBMultiplayer/SBMultiplayer.Client.dll" %command%

   Windows (no space before the &&!):
     cmd /c "set DOTNET_STARTUP_HOOKS=C:\path\to\STUNTBOOST\SBMultiplayer\SBMultiplayer.Client.dll&& %command%"

3) Start the game and press F8 (F8 again closes the menu). "Join a game" lists your Steam friends'
   games and the public games; below, type an SBLB lobby code (community website) or a server
   address (address:port). A password is asked for if the game has one.
   F7 takes you to the current round's map. Enter opens the chat (/help for commands),
   hold Tab to see the player list.
   F8 > Spectate to watch: Left / Right to switch player, F for the free camera.
   F8 > Host a game to host your own game (you're its admin); Steam friends join it
   from F8 > Join a game, without opening any port. Tick "Public game (anyone on Steam)"
   and anyone can join it from there. Or create an SBLB lobby and share its code (nobody opens a port).

Other players riding the same level show up as translucent boards.
The mod's interface follows the game's language (English or French).

Tournament organizers: SBMultiplayer/verify-replays.sh (Linux) or verify-replays.bat (Windows) re-simulates
the replays saved by the server with the game, to check the times (see docs/replay-verification.md on GitHub).

Problem? Send the SBMultiplayer/SBMultiplayer.log file.
More info: https://github.com/AsLirith/SBMultiplayerMod
